# Приложение - угадай флаг
## На экране будут изображены флаги, и надо будет угадать флаг какой страны изображен

**Автор** - Лазарев Иван, ИСП-242, дата сдачи - 05.10.2026

**Стек и версии:**
- Flutter 3.47.1
- Dart
- Платформа: Web (Chrome)
- IDE: VS Code
---
## Структура проекта:
1. **main.dart** - файл, в котором написан весь основной код
2. **gradient_container.dart** - градиент для фона
3. **styled.text.dart** - стилизация текста
4. **flag_quiz.dart** - виджет, в котором прописан алгоритм игры: рандомайзер флагов, кнопки выбора и перехода не следующий флаг и счетчик баллов
